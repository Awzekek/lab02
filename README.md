# Лабораторная работа №2

## Анализ веб-приложения и клиент-серверного взаимодействия

### Цель работы

Изучить принцип взаимодействия компонентов современного веб-приложения на примере реального цифрового сервиса, исследовав HTTP-взаимодействие между браузером и сервером, структуру запросов и ответов, использование cookies и работу API.

### Исследуемая информационная система

**Сервис:** Aviasales

**Вариант:** 7

**Ссылка:** https://www.aviasales.ru/

**Пользовательский сценарий:** поиск авиабилетов по маршруту.

Лабораторная работа является продолжением лабораторной работы №1 и использует тот же цифровой сервис и пользовательский сценарий.

### Результат

В работе исследованы HTTP-запросы и ответы при работе с Aviasales, определены используемые HTTP-методы и статус-коды, изучены параметры POST-запроса и JSON-ответа API, рассмотрены cookies, а также проанализировано взаимодействие Frontend, API и Backend.

На основе результатов исследования подготовлена схема взаимодействия компонентов веб-приложения.
